# UPayNow 文档索引

先安装，再按商户任务使用；API 和底层合约资料供接入开发者或维护者查阅。

## 商户与部署者

- [安装与 HTTPS 部署](INSTALLATION.md)：环境、持久数据目录、首次启动、三个访问入口、停止与备份。
- [商户操作手册](OPERATIONS.md)：从首次设密到添加网络、部署、查单、电脑/手机归集、错币错链找回及日常维护的逐步教程。
- [认证说明](AUTHENTICATION.md)：登录密码、恢复密钥、独立 API 凭据及忘记密码。
- [安全边界与上线核查](SECURITY.md)：服务器、钱包、确认数、未知交易、代币和一致性备份的限制。
- [问题反馈与联系](../README.md#问题反馈与联系)：普通问题、扩链和商业授权；安全漏洞先按[安全反馈指引](../SECURITY.md)私下联系。

## 商城接入开发者

- [商城 API、验签、重试和迟付](../backend/README.md)：开单、查单、部署选择、付款通知及显式接受迟付。
- [前端与服务接口](../frontend-v2/INTEGRATION.md)：静态页面角色、API 和手机专用入口的边界。
- [前端使用与开发说明](../frontend-v2/README.md)：页面、构建及相关开发检查。

付款认定、通知送达、商城履约、资金归集是不同状态。应以准确部署和链上付款记录认单，通知要验签，履约要幂等；不能把钱包截图、余额、HTTP 2xx 或归集成功当成完整履约证明。

## 部署和恢复技术资料

- [多链与商户部署](../backend/MULTICHAIN.md)：商户配置、确定性部署、已有合约导入及记录核验。
- [手机归集与配置](../backend/MOBILE-HANDOFF.md)：临时入口、固定 HTTPS、会话和发送。
- [归集票据与任务恢复](../backend/HANDOFF.md)：受限权限、原交易哈希、未知结果和手机/后台隔离。

- [多 CA 合约接口](multi-ca-interface.md)：支持币种、错币和批量逐项结果等底层语义，不代替商户操作教程。
