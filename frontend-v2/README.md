# UPayNow 用户界面

**简体中文** | [English](README.en.md)

这是 UPayNow 的管理台、顾客收银台和手机钱包确认页面。项目仓库：<https://github.com/LouieTang66/UPayNow>。页面使用同源真实服务数据，接口错误不能以虚构订单、余额或成功状态替代。

## 首次使用

在项目根目录执行 `npm ci && npm start`，按 [安装说明](../docs/INSTALLATION.md) 设置持久运行目录、登录密码/恢复密钥及所需 HTTPS 入口。新实例尚无已接入部署、Factory、payout、币种和订单；已开放网络预设由产品内置，不等于已替商户部署合约。登录后先添加自己的链并由自己的钱包确认部署 Factory，或导入已有的兼容 Factory。

不需要独立运行前端服务。管理页由后台提供，钱包部署/归集页面由各自专用服务提供；路由及权限见 [INTEGRATION.md](INTEGRATION.md)，逐步操作与异常恢复见 [完整操作手册](../docs/OPERATIONS.md)。

## 页面功能

- **总览**：当前部署的订单、付款和需要处理的事项。
- **订单**：查单、付款流水、原始金额/CA、收银台链接与相关归集记录。不同币种不合计成美元。
- **归集**：可归集、异常恢复和归集记录；可预览批量、确认手机归集或使用电脑钱包。正常归集其他支持币及明确确认后的错币处理仍保留。
- **付款通知**：查看通知投递情况，对可重试事件重新排队；显示成功不是商城已经完成履约的证明。
- **链与合约**：添加/导入自己的 Factory，查看链上身份和部署记录，可编辑显示名称但不改变合约。新建仅限已开放网络的 deterministic-v2 商户部署，选择网络会自动填写内置 RPC；公共入口由运营方预部署并经核验，签名钱包必须为固定 payout。固定 payout 与币种表部署后不可改；同链、同 payout、同版本不能通过重部署增加币种，换 payout 则另建部署并保留旧部署；历史合约可经核验导入。
- **商城接入**：由商城服务器 API 开单并验签、去重、幂等履约，参见 [商城接入](../backend/README.md)。管理凭据不能交给顾客页面。
- **设置**：密码、恢复密钥、独立 API 凭据及钱包连接等设置；可选 WalletConnect 需要部署者自己的 Reown Project ID，注入钱包/手机专用页无需该 ID。“辅助工具 → 手动创建一笔订单”用于测试或补单，正式订单仍由商城 API 创建。

顶部部署选择决定当前管理上下文。切换不停止其他部署扫描，不改写原订单，也不改变 Factory 或 payout。归集流程必须绑定开始时的部署，不能借切换网络改收款人。

`/pay/:token` 是正式顾客收银台，显示应付网络、代币 CA、金额、订单地址、二维码和核验状态。当前 UI 没有接受迟付按钮；商城后台可通过 API 明确接受已确认到账快照，见 [商城接入](../backend/README.md#商户明确接受超时付款)。手机部署/归集页只确认当前批准操作，不提供管理权限；必须核对网络与收款信息后由钱包明确确认并支付 gas。

## 钱包与安全提示

付款状态和归集状态分别展示；外层批量成功不代表逐项成功。连接钱包、打开二维码和预览都不发送交易。超时、断线或通道关闭保持结果未知；先找原哈希并恢复核验，不自动重发。人工登记结果会停止该钱包任务的自动观察，不是链上核验成功。完整手机链接是短期权限，禁止公开分享。

普通归集可由其他钱包付 Gas，资金仍只到固定 payout；专用错链找回要求目标链 payout 钱包签名。当前按链/部署操作，没有钱包分组或跨链归集队列。

登录使用服务端 HttpOnly 会话，前端不持久保存密码、恢复密钥或 API 凭据。手机短期 capability 可存于当前标签页 sessionStorage 以便刷新，不是永久权限，截止/作废由后台决定。

前端不能替代服务端资产/链身份核验、商城库存系统或履约事务。没有主网、实体钱包兼容或独立安全审计完成承诺；历史后端未确认审查线索集中在 [安全文档](../docs/SECURITY.md)。

## 开发者：构建与检查

构建入口为项目根目录 `npm run build`；前端输出位于 `frontend-v2/dist`，正式服务直接挂载该产物。钱包适配器由本前端独立打包。`npm run test:frontend-v2` 运行前端回归测试。
