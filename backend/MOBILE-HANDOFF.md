# 手机单次归集

新用户先读 [用户操作手册](../docs/OPERATIONS.md)。本页是专用手机归集能力链接，不是桌面 WalletConnect；专用错链找回暂不支持该手机入口，须在桌面使用注入钱包或 WalletConnect。

## 使用流程

1. 在管理台查看当前部署的可归集订单，预览并确认本批条目。
2. 创建本次手机入口二维码；使用手机钱包的内置浏览器打开完整链接。
3. 核对网络、Factory、固定 payout、批准订单和 CA。页面余额为创建时快照，实际执行时归集指定币种的全部余额，可能包含之后到账。
4. 连接自己的钱包并明确确认一笔归集交易，由钱包支付 gas。正常同链归集不要求该钱包等于 payout，资金仍只到固定 payout；不要与 v2 新建或错链找回的 payout 签名要求混淆。打开页面、连接账户、生成二维码均不发交易。
5. 保存钱包返回的原哈希，等待服务核验回执；逐项查看 SUCCESS / PARTIAL_FAILURE / REVERTED，不把外层成功当作全批成功。

“一键归集”面向已付足订单；人工选中归集不证明订单已经付足。电脑钱包路径、其他支持 CA 的正常归集以及明确确认后的错币处理仍是产品功能，所有资产只能到固定 payout。

## HTTPS 入口

标准启动 `npm ci && npm start` 默认管理端口 8790、归集专用网关 8791，均仅监听本机。物理手机不能访问电脑的 `127.0.0.1`，不得把本机二维码当作手机可访问地址。

推荐由部署者提供固定 `UPAY_HANDOFF_ORIGIN` HTTPS origin，反向代理到本机归集专用端口，保留 Host，严格匹配 Origin；不要将手机域名代理到管理服务。三个入口的配置见 [安装说明](../docs/INSTALLATION.md)。

若未配置固定手机 origin，可在用户确认后按需申请 Cloudflare Quick Tunnel。组件优先使用显式指定的可运行 cloudflared，其次系统 PATH；缺失时从官方来源按固定版本和 SHA256 校验自动下载，无需默认手工安装。显式路径错误会报错，不悄悄 fallback；详见 [组件说明](CLOUDFLARED.md)。普通启动不下载也不自动开放通道；最长 300 秒，不因刷新/访问续期。创建失败应停止，不应展示假可用链接。第三方通道无可用性承诺，平台可能接触流量；固定 HTTPS 模式不需要 cloudflared。可用 `UPAY_CLOUDFLARED` 指定可执行文件。

临时通道可在回执确认、超时、作废/拒签或手动关闭时结束；收起二维码窗口不等于作废。关闭通道不会取消链上交易或 UNKNOWN 任务。固定 HTTPS 入口持续提供网站，但票据本身仍有独立有效期。

## 凭证与权限

手机链接 fragment 携带本次短期 bearer capability，不是管理口令；拿到完整链接的人可以查看并尝试为批准的归集付 gas。不要公开二维码、完整链接或日志。专用服务不提供管理登录、订单列表或普通管理配置，不需要 Reown Project ID，也不向手机交付商户私钥。

批准范围绑定网络、Factory、payout、订单和币种，手机不能替换。票据过期仅限制网页发起，不改变 permissionless 合约，也不能撤销已下载调用数据或已广播交易。

断线、超时、关闭通道或未取得哈希都保持结果未知，UNKNOWN 不是失败，不自动再发。先在钱包查原交易并从管理台登记恢复；手机页在原有效授权、同一任务且无已知哈希等受限条件下可显式再次唤起钱包，不代表首次未广播。明确拒签后仍观察 64 区块；管理员人工 resolve 则停止自动观察，人工结果不是链上确认。恢复及撤销规则见 [HANDOFF.md](HANDOFF.md)。实体钱包、内置浏览器、TLS、网络以及 EIP-681 扫码能力需用自己的设备确认，不将自动化页面检查视为实体手机或主网验收。
