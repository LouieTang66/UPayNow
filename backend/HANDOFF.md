# 手机能力入口与异常恢复

手机归集使用 `/c/:id#capability`，手机部署使用 `/d/:id#capability`，分别由独立受限服务提供；使用步骤见 [手机归集](MOBILE-HANDOFF.md)和[部署/导入](MULTICHAIN.md)。这不是顾客收银台，也不是管理员登录入口。

面向新用户的完整流程见 [用户操作手册](../docs/OPERATIONS.md)。手机专用能力链接不同于桌面 WalletConnect；后者需要自己的 Reown Project ID（可先保存，不要求已有部署）。专用错链找回不支持本手机入口，可用桌面注入钱包或桌面 WalletConnect。

## 能力范围

- 归集票据使用随机 256-bit bearer 凭证，服务保存摘要；凭证位于 URL fragment，不在 query，不含后台凭据或私钥。
- 手机页面会将凭证保存在本标签页 sessionStorage 并清理地址栏 fragment 以支持同标签页刷新。该存储不是永久授权，服务器有效期和撤销始终有效；使用共享设备后应关闭对应会话。
- 完整链接的持有人能查看并尝试执行本次批准操作；因此不公开分享二维码、链接、浏览器存储或截图。
- 链、Factory、payout 和批准的订单/币种或部署参数由服务绑定，手机不能替换；手机服务不提供管理登录、订单列表和其他普通管理 API。
- 单张归集票最多绑定一个持久化交易任务，同一发送者可恢复尚未开始的 PREPARED，不因刷新再建任务。

## 状态与恢复原则

1. **尚未开始**：PREPARED 可在允许条件下恢复或作废释放；过期/撤销阻止新 prepare/begin。
2. **开始发送**：先持久化 UNKNOWN，再将发送数据交给钱包。只有明确拒签才登记拒签，拒签声明不等于链上未广播证明。
3. **未知结果**：UNKNOWN 不是失败；断线、超时、刷新、隧道关闭或登记失败均不自动取消、不自动重发。保存任务 ID，查找钱包原交易哈希，再登记核验。手机页仅在原授权和截止时间内、同一任务/发送者/批准范围且尚无已知哈希等受限条件下，允许用户显式再次唤起钱包；该操作不创建第二个任务，不证明第一次未广播。
4. **已提交**：核对实际链、账户、交易目标、calldata、value、原哈希及真实回执；钱包返回哈希不是成功收据。
5. **已完成**：逐项检查结果，部分失败不能展示为全部成功。归集结果也不替代付款状态。

归集管理员可通过 `POST /api/handoffs` 创建票据，`GET /api/handoffs/:id` 查看，`POST /api/handoffs/:id/revoke` 作废，`POST /api/handoffs/tunnel/close` 关闭临时通道。撤销未开始票据与关闭窗口是不同动作；作废不会取消 UNKNOWN 或已广播交易。

固定 HTTPS 入口在票据过期/作废后，已开始的原任务仍可能允许按受限规则补登记原哈希并查看回执；这不允许重新开始新发送。临时隧道关闭后原地址不可访问，应回管理台恢复，不用后续新通道复活旧票。

## 网页撤销不等于链上撤销

合约归集本身允许任何人付 gas 调用，资金仍只能到固定 payout。二维码过期、网站关闭或票据撤销不可能撤回已经下载的调用数据，也不能取消钱包已经广播的交易。部署交易同样不能由关闭通道撤销。

创建时余额只是快照，执行时归集指定 CA 的全部当前余额；迟到余额、付款认定、库存和退款仍由各自业务流程处理。正常同链归集的 gas 发送者不必等于 payout；新建 v2 商户部署和专用错链找回则要求 payout 签名，不能混用规则。

归集任务明确拒签后仍观察后续 64 区块，拒签不是未广播证明。管理员人工 resolve 将任务记为 ABANDONED 并停止自动观察；人工结论不经链上验证，不是成功回执、付款状态或资产退款，须先独立核对钱包和链上记录。

固定/临时 HTTPS 配置见 [安装说明](../docs/INSTALLATION.md)。历史候选哈希恢复和 RPC 保密等未确认审查线索见 [安全说明](../docs/SECURITY.md)；没有因重写此文自动消除风险。
